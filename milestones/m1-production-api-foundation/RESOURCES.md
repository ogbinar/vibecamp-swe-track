# Resource guide

Seek primary specifications or official references for HTTP method/status semantics, media types, OpenAPI, JSON/schema validation, FastAPI response modeling, Pydantic strictness, and decimal arithmetic. For standards, prefer the governing specification; for framework details, match the pinned version.

Reject “CRUD tutorial” resources that omit error contracts, retries, pagination ordering, or compatibility. Record which consumer problem each selection resolves and test all examples locally.
