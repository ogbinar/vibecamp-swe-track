# Resource guide

Use current PostgreSQL primary docs for data types, constraints, indexes, transactions, and `EXPLAIN`; SQLAlchemy 2 docs for typed mappings/session lifecycle; Alembic docs for migrations; Docker docs for Compose volumes; and pytest docs for fixtures.

Select examples that include failure/rollback and existing data. Reject ORM-first material that never shows emitted SQL or treats autogenerated migrations as reviewed. Record database/framework versions because behavior and syntax vary.
