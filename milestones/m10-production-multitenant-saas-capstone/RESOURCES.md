# Resource guide

Select current primary documentation for PostgreSQL backup/restore/migration behavior; Docker image reproducibility; GitHub Actions artifact/security controls; the chosen deployment platform; OpenTelemetry semantic conventions and backend privacy controls; and authoritative tenant/security/incident guidance.

Require version-matched restore commands, explicit data handling, and failure/rollback coverage. Reject vendor diagrams without runnable recovery, observability “best practices” without questions/owners, and deployment tutorials that rebuild after tests. Record access date because platforms evolve.
