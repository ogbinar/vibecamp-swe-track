# Tools earned here

- **uv + lockfile:** reproducible dependency resolution and command execution; avoid a second package manager.
- **FastAPI/Pydantic:** smallest typed HTTP slice; do not build framework abstractions.
- **pytest + HTTPX:** prove behavior across the API boundary and one configuration unit seam.
- **Ruff:** fast, deterministic static feedback; keep configuration minimal.
- **GitHub Actions:** repeat the documented clean path. It is feedback, not evidence that deployment is safe.

No PostgreSQL, container, task runner, or deployment platform yet. Earn a task runner only after command drift is observed; remove any tool whose setup exceeds the problem it prevents.
